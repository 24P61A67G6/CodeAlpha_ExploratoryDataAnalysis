# CodeAlpha Task 2 – Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis on the Titanic dataset using Python.

## Tools and Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Activities
- Loaded and explored the Titanic dataset.
- Identified missing values.
- Analyzed passenger survival.
- Compared survival by gender and passenger class.
- Visualized age and fare distributions.
- Performed correlation analysis.
- Conducted Chi-square hypothesis testing.
- Cleaned missing values.

## Conclusion
This project helped me understand data exploration, statistical analysis, data cleaning, and visualization using Python.
